# FPGA Bitstream Build — xc7k480t (Vivado 2025.2)

## Quick build (production)

```bash
cd /path/to/chisel-npu

# Step 1 (if Chisel sources changed): regenerate top.sv
make build   # runs sbt inside fangruil/chisel-dev:amd64 Docker

# Step 2: build bitstream (auto-bootstraps project on first run, ~45 min cold)
~/Xilinx/2025.2/Vivado/bin/vivado -mode batch \
    -source  ip/vivado/xc7k480t/scripts/build_v9_npu_full.tcl \
    -journal ip/vivado/xc7k480t/scripts/build_v9_npu_full.jou \
    -log     ip/vivado/xc7k480t/scripts/build_v9_npu_full.log
```

Output: `ip/vivado/xc7k480t/top_v9_npu_full.bit` (~17 MB, WNS ≥ +0.020 ns)

  scripts/

## Bootstrap (first-run project creation)

`bootstrap_project.tcl` is called automatically by `build_v9_npu_full.tcl`
when `ip/vivado/xc7k480t/proj/npu_migrate.xpr` does not exist. It:

1. Creates a fresh Vivado project (part `xc7k480tffg1156-2`)
2. Sources `ip/vivado/xc7k480t.reference/scripts/recreate_bd.tcl` — creates
   the V9 BD with all 19 IP cells via `create_bd_cell` TCL calls
3. Copies `mig_a.prj` alongside the MIG XCI (required for MIG to load)
4. Runs `generate_target all` (regenerates all IP HDL, ~10–20 min cold cache)
5. Runs `make_wrapper` to create `top_wrapper.v`
6. Runs all OOC IP synthesis runs + main `synth_1` in parallel (`launch_runs`)
7. Waits for ALL runs (OOC sub-runs must finish before `write_checkpoint`)
8. Copies IP DCPs from `IP_OUTPUT_DIR` (gen/) → `IP_DIR` (srcs/) so
   `link_design` in impl can resolve them (Vivado INBB-3 workaround)
9. Calls `write_checkpoint` after `open_run synth_1` to merge OOC results
   into the main DCP (21 MB, no black boxes)

**If bootstrap fails:** delete `proj/` and retry:
```bash
rm -rf ip/vivado/xc7k480t/proj/
```

## V9 BD topology (V9 = production)

```
XDMA (axi_aclk = 125 MHz)
  M_AXI        → axi_cc_xdma_in → axi_clkconv_xdma(125→133 MHz)
                  → axi_dwidth_xdma(128→512 bit) → MIG C0 @ 0x0 [2 GB]
  M_AXI_BYPASS → axi_clkconv_byp → byp_dw(128→32) → byp_pc → ctrl_lite

NPU subsystem (fabric_aclk = 125 MHz from clk_wiz_fabric MMCM):
  ctrl_lite ←→ npu_dma_master ←→ MMALU (top.sv, K=32)
  npu_dma_master → axi_clkconv_npu(125→133 MHz)
                 → axi_dwidth_npu(128→512 bit) → MIG C1

MIG C0/C1 control:
  mig_c0_ctrl_vip / mig_c1_ctrl_vip (idle AXI-Lite VIP stubs)
```

**No SmartConnect** — removed in V6. The SmartConnect was replaced because its
internal `aclk1` domain inference breaks when M00_AXI is routed through an
external clock converter.

## Validation step ladder (V0–V9)

Each step proves one NPU component is cold-boot safe. All pass 9/9 smoke tests.

| Step | Script | What it adds |
|:-----|:-------|:-------------|
| V0 baseline | `build_v0_baseline.tcl` | Reference design, no changes |
| V1 no_mb | `build_v1_no_mb.tcl` | Remove MicroBlaze + clk_wiz |
| V2 bypass_ctrl | `build_v2_bypass_ctrl.tcl` | BYPASS path + ctrl_lite |
| V3 mmcm | `build_v3_mmcm.tcl` | Fabric MMCM (125 MHz) |
| V4 byp_cdc | `build_v4_byp_cdc.tcl` | BYPASS clock crossing |
| V5 xdma_cc | `build_v5_xdma_cc.tcl` | XDMA→fabric clock crossing |
| V6 no_smc | `build_v6_no_smc.tcl` | Remove SmartConnect; NPU flat AXI chain |
| V7 dma_master | `build_v7_dma_master.tcl` | npu_dma_master → MIG C1 |
| V8 npu_stub | `build_v8_npu_stub.tcl` | Chisel mmalu_stub.v (synthesis shape) |
| V9 npu_full | `build_v9_npu_full.tcl` | Real top.sv (K=32, firtool-1.62.1) |

Run a step (build + flash + test):
```bash
ip/vivado/xc7k480t/scripts/run_step.sh v6_no_smc
```

## Key bitstream settings

Applied in `migrate_lib.tcl::run_impl_and_write_bit` before `write_bitstream`:

```tcl
set_property CONFIG_MODE                 SPIx1 [current_design]
set_property BITSTREAM.CONFIG.CONFIGRATE 3     [current_design]
```

Target COR0 = `0x02003fe5`. Check with:
```python
python3 -c "
import struct
data = open('ip/vivado/xc7k480t/top_v9_npu_full.bit','rb').read(400)
for i in range(len(data)-4):
    if data[i:i+4] == b'\xaa\x99\x55\x66':
        for j in range(i+4, i+100, 4):
            if struct.unpack('>I',data[j:j+4])[0]==0x30008001:
                print(hex(struct.unpack('>I',data[j+4:j+8])[0]))
        break
"
```

## RTL source files

### `npu_ctrl_lite.v`
AXI4-Lite slave at BAR2+0x0. Single 32-bit CTRL register:
- bit[0] W: `start` — 1-cycle pulse to DMA master (self-clears)
- bit[1] RO: `done` — asserted when DMA write-back finishes
- bit[2] RO: `busy` — asserted while DMA is active

### `npu_dma_master.v`
AXI4 master (128-bit, 64-bit addr, K=32). Reads matrices A/B/Accum from
MIG C1 (default base addrs: `0x1000_0000_0000_0000` + offset), kicks MMALU,
waits for `io_clct`, writes result back. Uses pipelined AXI read beats
(ARLEN=1 for 32B matrices, ARLEN=7 for 128B accumulator/result).

### `npu_subsys.v`
Wrapper instantiating `npu_ctrl_lite` + `npu_dma_master` + `MMALU` (from
`top.sv`). Exposed as a BD module cell with flat `s_axil_*` and `m_axi_*`
ports plus `c0/c1_init_calib_complete` status inputs.

### `top.sv` (repo root)
Chisel-generated SystemVerilog for the `MMALU` module (K=32, N=8, 32-bit
accumulators). Generated by `make build` inside `fangruil/chisel-dev:amd64`
Docker. 1.7 MB, firtool-1.62.1.

## Troubleshooting

| Problem | Fix |
|:--------|:----|
| `build_v9_npu_full.tcl` exits immediately — no project | Run bootstrap manually: `source ip/vivado/xc7k480t/scripts/bootstrap_project.tcl` in Vivado TCL |
| OOC synthesis stalls | Check `proj/npu_migrate.runs/top_xdma_0_0_synth_1/runme.log` |
| WNS < 0 after impl | Try `Explore` routing directive; check fabric clock frequency in `_apply_v3.tcl` |
| Black-box errors (`INBB-3`) during impl | IP DCPs not copied to `IP_DIR`; re-run bootstrap |
| `module top_wrapper not found` | `top_wrapper.v` not in fileset; re-run bootstrap |
| Chisel `top.sv` compile errors (Scala) | The Scala sources have compile errors unrelated to FPGA build; use the existing `top.sv` if it exists |
