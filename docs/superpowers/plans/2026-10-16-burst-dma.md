# Burst/Bulk DMA (Phase 2b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise data-movement efficiency (bytes/cycle) so memory traffic is not the IPC bottleneck: batch multiple vectors into long back-to-back AXI bursts and pipeline requests, instead of one short burst per vector with an `IDLE` round-trip.

**Architecture:** fastvdma-inspired. Split our single-request FSM into (a) a **TransferSplitter** that turns a bulk request into back-to-back max-length AXI bursts (≤256 beats, 4 KB-barrier aware), and (b) address/data-phase-decoupled reader/writer engines fed by a streaming data path, so bursts pipeline with no per-burst software round-trip. Keep full backward compatibility: existing per-vector requests must behave exactly as today.

**Tech Stack:** Chisel 6.7.0, `EphemeralSimulator`, ScalaTest, Docker toolchain.

**Spec:** `docs/superpowers/specs/2026-10-15-engine-macs-per-cycle-design.md` (roofline §); reference: https://github.com/antmicro/fastvdma (`Worker/TransferSplitter.scala`, `Frontend/AXI4Reader.scala`, `Frontend/AXI4Writer.scala`).

## Global Constraints

- K=32, W=16 primary; `top/top.scala` must not be modified.
- Backward compatibility: the existing per-vector request interface (`req_dir/width/rf_addr/l3_addr`, drain/done, RF ports) keeps its exact current behavior — `NpuDmaEngineSpec` must stay green unchanged.
- AXI4 at 128-bit for now (the `AxiRamModel` is 128-bit); wider beats are a follow-on.
- Tests use `chisel3.simulator.EphemeralSimulator`; run `tool/test-specific-spec.sh <Spec>` (~5–40 min).
- Do NOT commit `target/`, `test_run_dir/`, or `top.sv`.

## Baseline (measured)

- One `vse32` (128 B) = one 8-beat INCR burst, address+data serialized in one FSM, then `IDLE`. Trace: ~13 cyc per 128 B store ≈ 9.8 B/cyc vs the 16 B/cyc 128-bit ceiling (~61%).

## Review Focus

1. **Backward compatibility** — per-vector requests byte-identical (`NpuDmaEngineSpec` unchanged). (All tasks.)
2. **No request loss/duplication** at burst-split boundaries (4 KB) and at back-to-back handoff. (Task 2/3.)
3. **Data integrity** across a multi-vector bulk transfer (every byte, every vector). (Task 3.)
4. **No AXI protocol violation** (AWLEN ≤ 255, no burst crossing a 4 KB boundary, WLAST/LAST correct). (Task 2/3.)

### Task 1: DMA throughput metric + pipelined back-to-back requests

**Files:**
- Modify: `src/main/scala/dma/npuDmaEngine.scala`
- Create: `src/test/scala/dma/NpuDmaThroughputSpec.scala`

**Interfaces:**
- Consumes: the current `NpuDmaEngine` request interface.
- Produces: `io.req_ready` asserted as soon as the current burst's **data phase** has started (not only after `DONE`), so a new request can be accepted and its address phase overlapped with the tail of the previous data phase — without changing any per-request completion semantics.

- [ ] **Step 3: Implement** request pipelining: assert `req_ready` earlier (once the data phase is streaming) and latch the next request while finishing the current response; keep the timeout-retry patterns. Do NOT alter the RF write/read semantics or the per-request `done` timing.
- [ ] **Step 4: Verify** the new spec PASS and `dma.NpuDmaEngineSpec` unchanged/PASS.

### Task 2: Bulk multi-vector transfer (long bursts)

**Files:**
- Modify: `src/main/scala/dma/npuDmaEngine.scala`
- Modify: `src/test/scala/dma/NpuDmaThroughputSpec.scala`

**Interfaces:**
- Produces: a bulk request path — `io.req_count` (e.g. `UInt(5.W)`, 1 = current behavior) and new dirs (4 = bulk L2R, 5 = bulk R2L) that move `count` consecutive vectors between a contiguous L3 region and consecutive RF registers. Implement the fastvdma `TransferSplitter` idea: split `count × beats` into ≤256-beat bursts that never cross a 4 KB boundary, streamed back-to-back with no `IDLE` between them.

- [ ] **Step 1: Write the failing test**: a bulk store of `count=8` VR vectors (1 KiB) in one logical transfer; assert every byte correct and bytes/cycle ≥ 15; a bulk load of 8 VR vectors into consecutive RF registers, asserting the RF write pulses and data.

- [ ] **Step 3: Implement** the bulk path + splitter (4 KB barrier, ≤256 beats). `count=1` must reproduce the current behavior exactly.
- [ ] **Step 4: Verify** `NpuDmaThroughputSpec` + `dma.NpuDmaEngineSpec` PASS.
- [ ] **Step 5: Commit.**
